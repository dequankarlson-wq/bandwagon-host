# 搬瓦工官网与 VPS 选购指南：入口、套餐和下单步骤

搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的 VPS 服务商，提供基于 KVM 虚拟化的服务器。VPS 可以用于网站建设、Linux 学习等场景：用户租用服务器资源，再自行选择系统、管理服务和维护自己的数据。与购买一个现成的网站服务不同，使用 VPS 通常需要自己处理系统和应用的日常管理。

如果你希望学习 Linux、尝试部署网站，或正在比较不同机房和流量额度，可以先从预算、使用需求和管理能力出发，再挑选套餐。搬瓦工提供 KiwiVM 控制面板作为服务器管理入口；对于初次接触 VPS 的用户，购买前也值得先想清楚自己是否愿意学习基本的服务器管理操作。

## 官网入口：如何辨别不同域名

搬瓦工官网的主域名是 `bandwagonhost.com`。参考资料同时列出了 `bwh81.net`、`bwh89.net`、`bwh88.net`、`bwh1.net` 和 `bwh8.net` 等官方镜像域名。这些入口对应同一服务，账号、服务和数据互通：通过其中一个入口购买后，也可以使用同一账号从其他入口登录管理。

不同网络环境下，各域名的访问情况可能不同。遇到页面打不开时，可以尝试资料中列出的其他入口；不要把某个域名在某个地区的可访问状态当作永久不变的条件。注册、登录或付款之前，应核对浏览器地址栏中的域名，避免把教程站或其他不熟悉的网站误当成账户入口。官网界面为英文，中文教程可以作为辅助阅读材料，但账户信息和支付操作应在官方入口完成。

### 先确定流量与预算

如果主要用于入门学习或预算有限，可以先比较两种普通 KVM 方案。A 的资料价格为年付，月流量是 1TB；B 提供半年付和年付的参考价格，月流量为 2TB。流量需求较大时，B 的额度更高，但也要结合付款周期和实际费用判断，而不是只比较单次付款金额。

如果希望选择 CN2 GIA-E，A 和 B 的主要区别之一同样是月流量：前者 1TB，后者 2TB。资料还列出了不同的季付和年付价格，以及多个机房选项。可以先估算每月大致需要多少流量，再查看订单页面中自己需要的机房是否可选；一个套餐列有多个机房，并不意味着每个时点都应假定所有选项均可购买。

香港 CN2 GIA 两个方案分别列有 500GB 和 1TB 月流量，参考价格明显高于表中的普通 KVM 方案。若位置是选择的重要因素，可以将它们与其他方案一起比较，但仍应先核对每月流量是否足够、月付或年付是否符合预算。地理位置和线路名称本身不能保证某个用户的实际延迟或访问速度。

### 再看付款周期与机房

表中的年付价格和较短周期价格不是同一时间长度的费用。比较时应先看自己愿意一次支付多少，以及准备使用多久，再分别查看可选周期的总价；不要把半年、季度和一年的标价直接当作同一周期比较。并非每个套餐都提供表中所有周期，最终以所选方案的页面为准。

机房和线路也应与用途一起考虑。例如，建站时需要关注访客所在地区，学习用途则可以先考虑预算和基本资源。参考资料列出的线路名称有助于缩小选择范围，但无法替代对具体方案和当前网络状况的核对。如果页面上的机房列表、价格或库存与上表不同，以实际页面信息为准。

## 搬瓦工购买教程：注册到付款

1. **进入官网并浏览方案。** 可从[官网套餐与库存入口](https://bwh81.net/aff.php?aff=85082)查看在售产品，也可从上表进入具体套餐。先确认产品名称、月流量、配置和可选机房，避免误选外观相近的方案。
2. **注册账号。** 在英文界面找到 `Register`，按页面要求填写邮箱、密码、姓名和地址等信息。使用真实资料，并确认邮箱可以正常接收邮件；后续订单和服务信息需要通过账号及邮箱查看。
3. **选择套餐与付款周期。** 查看所需方案是否有库存，按页面提供的选项选择周期和机房。表格中的价格只是参考，不同套餐提供的周期不一定相同；加入购物车前应检查页面实际显示的选项。
4. **加入购物车。** 确认选择后使用 `Add to Cart`。进入购物车再次核对产品、机房、流量和计费周期；如果所需选项不可用，不要仅凭套餐名称假定订单内容正确。
5. **填写优惠码并检查金额。** 在结算页找到 `Promotional Code`，输入下文列出的代码，查看系统是否接受以及订单金额如何变化。未显示折扣时，先核对输入和适用条件，不要自行假设优惠已经生效。
6. **选择支付方式并完成订单。** 参考资料提到支付宝、PayPal、信用卡和银联；可用方式以结算页面实际显示为准。选择后核对最终应付金额，再按页面提示支付。完成后留意邮箱中的 Welcome 邮件及订单信息，不必假定服务一定会在某个固定时间内开通。

英文页面中，`Register` 是注册，`Add to Cart` 是加入购物车，`Promotional Code` 是优惠码输入项。操作时重点核对字段和订单内容；如果当前页面的文字或流程与上述说明不同，应以页面实际提示为准。

## 优惠码和付款前的核对

参考资料列出的优惠码为 **`BWHCGLUKKB`**，所述优惠为约 6.77% 的循环折扣。循环折扣与一次性减免的区别在于，资料描述它可用于后续续费；但优惠能否应用、具体金额和适用条件都需要在结算时确认，不能保证代码现在仍然有效。输入后应查看订单是否接受代码，以及优惠前后的金额变化。

提交付款前，建议按以下顺序再检查一次：

- **产品**：名称和链接对应的是想购买的方案，而不是同系列的另一档。
- **资源与位置**：月流量、其他配置和选定机房符合用途；需要的系统也在支持范围内。
- **费用**：付款周期、当前应付金额和页面显示的续费金额都已看清。优惠是否影响后续账单，以订单及服务商说明为准。
- **账户**：邮箱和资料填写正确，能收到与订单相关的邮件。

这样核对的目的不是追求表中最贵或最便宜的方案，而是让所选流量、机房和支付安排与自己的实际需求一致。

## 常见问题

### 官网打不开或页面是英文，怎么办？

先检查输入的域名是否正确，再尝试上文列出的其他镜像域名。参考资料说明这些入口的账号和服务互通，但各入口的访问情况可能随网络环境变化。页面为英文时，可以对照注册、购物车和优惠码字段逐项操作；涉及账户和付款的操作仍应在确认过的官网域名内进行。

### 预算有限，应该优先看价格还是流量？

两者都要看。先确定能接受的一次付款金额和使用周期，再估计每月需要的流量；如果只看低价而忽略流量，可能选不到符合用途的方案。同样，较大的流量额度也不必然意味着更适合每个人。最后还要核对配置、线路和机房，而不是把价格作为唯一判断依据。

### 购买后可以退款吗？

参考资料提到购买后 30 天内可以申请退款。申请并不等于一定获批，具体资格、条件和办理方式应以服务商当时的退款政策为准。购买前先阅读相关条款，比付款后才确认更稳妥。
